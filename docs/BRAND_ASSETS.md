# Feasty brand assets

The operations console uses the approved Feasty logo artwork from the connected Google Drive brand-assets folder.

The current UI imports the orange SVG logo as `/brand/feasty-logo-1.svg`. The asset is stored under `client/public/brand/` so it is served as a normal static resource and remains available in production builds. The dark hero treatment uses the same approved artwork with a CSS light treatment for contrast.

The source folder is the Feasty brand-assets Drive folder supplied for this project. Additional variants remain available in Drive for later use in onboarding, exports, and notification templates. The repository does not include unrelated social-media mockups or stationery files because they are not required by the console UI.

The primary observed brand orange is `#ff611d`. The interface retains the existing neutral surface system so the orange remains an action and identity color rather than overwhelming the operations workflow.
